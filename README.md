Sky Courier: Coral Island Run — a complete, original flight game that plays offline in a desktop browser from its own files. Take off from runway 18, fly all 8 rings over the Coral Islands, then land back on the runway. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network request.

## How to fly

- **↑ / ↓** pitch, **← / →** bank and turn
- **Shift / Ctrl** throttle up / down, **B** brake on the runway
- **Mouse:** drag to steer
- **Space** start / restart, **P** pause, **M** mute

Three stages: takeoff past 300 ft, the 8-ring run over the islands (rings add fuel and score), and a landing on runway 18 under 130 kt with wings level. Fuel burns with throttle, terrain and the sea are unforgiving, and you have 3 lives.
